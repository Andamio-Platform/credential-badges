joins or leaves this list is described in [`GOVERNANCE.md`](GOVERNANCE.md).

Maintainers are listed as individuals. Affiliation is shown because
organizational diversity among maintainers is a project goal, and a
foundation will ask for it.

## Maintainers wanted

Every active maintainer is currently affiliated with Andamio Platform. A
foundation such as LF Decentralized Trust expects multiple maintainers, ideally
from different organizations. A proposal with a single maintainer, or with
every maintainer from one company, is weak. The project is especially
looking for maintainers who:

- run or plan to run their own deployment as an issuer;
- build an evidence adapter for a trust source other than Cardano/Andamio;
- maintain an Open Badges 3.0 or W3C VC verifier, wallet, or display surface.

If that is you, start with [`CONTRIBUTING.md`](CONTRIBUTING.md) and say so in
an issue.
